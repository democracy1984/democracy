# 🕊 Democracy Userbot

Сатирический Telegram-юзербот: следит за действиями ботов-модераторов в группах,
ведёт статистику мутов и банов, клеит стикеры-голубей в чат и агитирует «жертв
режима» в личку, раздаёт достижения за нарушения.

## Возможности

- **Мониторинг модерации** — ловит сообщения ботов-модераторов (MissRose, THM Chatbot),
  парсит муты/баны, жертву, срок и причину наказания, сохраняет всё в SQLite.
- **Стикеры-реакции** — 🕊 в чат на каждое наказание, 🦅 при входе нового участника.
- **Агитация в ЛС** — пишет «несправедливо замученным» с призывом к демократии,
  но только тем, с кем уже есть диалог, и только если пользователь не отписался.
- **Статистика** — карточки на PIL (PNG или анимированный GIF с «матричным» фоном)
  с топами нарушителей, причинами и персональной статистикой.
- **Достижения** — 9 уровней: от «Первого удара режима» (1 мут) до
  «Демократии Выборов нет» (1984 мута).
- **Исторический скрапер** — при первом запуске (пустая БД) проходит по всем
  чатам и собирает историю модерации.

## Мониторируемые боты

Все боты задаются в одном месте — файл `bots.py` (список `MODERATOR_BOTS`).
Каждая запись содержит имя, статический ID (если известен) и/или username
для динамического резолва при старте.

| Бот | Как попадает в мониторинг |
|---|---|
| **THM Chatbot** | Известный ID `7945156565` задан в `bots.py` (`bot_id`), попадает в `ALLOWED_MODS` сразу |
| **MissRose** (`@MissRose_bot`) | ID резолвится динамически при старте в `main.py` по `bot_username` и добавляется в `ALLOWED_MODS`. Если резолв не удался — остаётся только ID из `bots.py` |

`ALLOWED_MODS` — плоский рабочий список ID, который строится из `bots.py`
и реэкспортируется через `config.py` (чтобы существующие импорты не менялись).
Фильтрация событий: `handlers/moderation.py` пропускает только сообщения от
`sender_id in ALLOWED_MODS`.

**Чтобы добавить/убрать бота** — правьте только `bots.py`, больше нигде
ID ботов не дублируются.

## Установка

Требуется Python 3.10+ (проверено на 3.12 и 3.14).

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

## Настройка

1. **API-ключи** — по умолчанию используются публичные ключи из документации
   Telethon. Для своего аккаунта получите собственные на https://my.telegram.org
   и задайте их через переменные окружения:
   ```bash
   export TELEGRAM_API_ID=123456
   export TELEGRAM_API_HASH=ваш_хэш
   ```
   либо подставьте значения напрямую в `config.py`.
2. **Сессии** — файлы `secrets/my_account.session`. При первом запуске Telethon
   попросит номер телефона и код; файл создастся сам.
   `secrets/scraper_session.session` — остаток от старого отдельного скрапера,
   для работы не обязателен.
3. **Список ботов** — файл `bots.py` (см. раздел выше).
4. **Стикерпак** — `STICKER_PACK_NAME` в `config.py`; аккаунт должен иметь
   доступ к паку, иначе стикеры просто не отправляются.

## Запуск

```bash
.venv/bin/python main.py        # основной юзербот
.venv/bin/python getchatid.py   # посмотреть ID своих чатов
```

При старте аккаунт должен быть уже авторизован. Если база пуста, сначала
запустится исторический скрапер (может занять время из-за FloodWait).

## Команды в ЛС

| Команда | Действие |
|---|---|
| `/stats` | своя статистика (или статистика автора сообщения, если ответить на него) |
| `/top` | ТОП-15 нарушителей и ТОП-5 причин |
| `/progress` | шкала достижений |
| `/help` | список команд |
| `/chats` | список групп/каналов аккаунта |
| `/stopspamming` | вкл/выкл уведомления в ЛС (повторный вызов включает обратно) |

В публичных чатах работают только `/stats` и `/top` (и отдают картинкой).

## Идентификация нарушителей

Основа — **user_id** (глобально уникален и неизменяем). `username` — вторичный
ключ (тоже однозначен, но может отсутствовать или меняться). Отображаемое имя
(`victim_name`) используется как подпись для показа и как последний фолбэк:

- если бот прислал наказание **без ID и без @username**, ID ищется по имени —
  но только если это имя во всей базе однозначно указывает на одного человека
  (`lookup_user_by_victim_name`). Неоднозначные имена (однофамильцы, заглушки
  вида `.` или пустых строк) не угадываются;
- когда ID всё же становится известен, он **бэкфиллится** в старые записи с этим
  именем, где ID не сохранился (`backfill_victim_user_id`). Существующие ID
  никогда не перезаписываются;
- кулдаун от повторов в `handlers/moderation.py` работает только по стабильным
  ключам (ID, иначе username) — однофамильцы больше не схлопываются в одного.

### Смена имени и username

Имя и username хранятся в записях на момент наказания, поэтому со временем
могут устареть. `identity.py` синхронизирует их со свежим профилем Telegram,
как только человек снова попадается боту:

- любое входящее сообщение (ЛС или группа) — `handlers/pm_dialogs.py`;
- новое действие бота-модератора против него — `handlers/moderation.py`;
- вызов `/stats` или `/top` — свежие имена берутся из Telegram сразу,
  а записи в БД обновляются (`resolve_current_names`).

Обновляются **все** записи пользователя, включая старые варианты имени. Так
`/stats` и `/top` не показывают старый ник, даже если человек сменил его
после последнего наказания и даже если раньше писался иначе.

### Разовый бэкфилл имён

Синхронизация ленивая — срабатывает, когда человек снова активен. Чтобы
обновить сразу всю базу, есть `backfill_names.py` (бот должен быть остановлен):

```bash
.venv/bin/python backfill_names.py            # обновить все профили
.venv/bin/python backfill_names.py --dry-run  # предпросмотр без записи
```

Скрипт проходит по всем `user_id` из базы, тянет актуальные профили из
Telegram и обновляет записи. Идемпотентен, обходит FloodWait.
`DEMOCRACY_DB` и `DEMOCRACY_SESSION_DIR` позволяют запустить его на копии.

## База данных

SQLite `bot_stats.db` (в git не попадает):

- `actions` — все наказания: чат, пользователь, тип (mute/ban), срок, причина, время;
- `pm_opt_out` — кто отписался от ЛС.

Соединение создаётся один раз в `database.py` и переиспользуется
(режим WAL, индексы по `user_id`, `chat_id`, `action_type`).

## Примечания

- Реакция 🕊 (`handlers/reactions.py`) срабатывает на любые сообщения
  с «свобода/демократия/выборы/1984», включая свои собственные, — так и задумано.
- В ЛС бот пишет первым только тем, с кем диалог уже существует.
- «Матричный» фон для карточек (`matrix_bg.gif`) скачивается автоматически
  при первом запуске и в git не попадает.
